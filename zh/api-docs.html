API 参考文档

GrokXNews API 允许您以编程方式管理任务、获取结果并与您的系统集成。

认证 (Authentication)

所有 API 请求都需要在 Header 中包含 API Key。

Authorization: Bearer YOUR_API_KEY

任务接口

GET /api/v1/tasks

获取当前用户的所有任务列表。

响应示例

{ "data": [ { "id": "task_12345", "name": "每日科技新闻", "status": "active", "schedule": "0 9 * * *", "created_at": "2025-02-10T08:00:00Z" } ], "meta": { "total": 1, "page": 1 } }
POST /api/v1/tasks

创建一个新的自动化任务。

请求参数

参数名 类型 必填 描述
name string 是 任务名称
prompt string 是 给 AI 的指令
schedule string 是 Cron 表达式

请求示例

{ "name": "竞品监控", "prompt": "分析这几家公司的最新动态...", "schedule": "0 10 * * 1" }
